# Changelog

## 0.1.0

The first release.

- **Hold-to-talk dictation** into any app: hold Right ⌘ (or fn, Right ⌥,
  Right ⌃), speak, release. Double-tap for hands-free; Esc cancels.
- **Live transcript at the notch** while you speak.
- **On-device speech models** on the Neural Engine: Parakeet v3 (25
  languages, default), Parakeet v2, Underdog Bark 3.0 and Bark 3.0 Plus;
  plus Parakeet v3 and Moonshine on the CPU. Download, switch and delete
  them in Settings or the menu bar.
- **Command Mode**: select text and say how to change it (uses Claude with
  your own API key).
- **Styles per app**, a **dictionary** for names and jargon, and searchable
  **history** with Undo.
- **Menu bar menu**: start dictation, paste or copy recent transcripts,
  switch microphone or model.
- **Welcome guide** for permissions, model download and a first try.
