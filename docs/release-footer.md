### Install

**Homebrew:** `brew install --cask hiteshbandhu/zappp/zappp`

**DMG:** download `zappp-*.dmg` below, drag zappp to Applications, then
right-click it → **Open** → **Open** the first time (zappp isn't notarized by
Apple yet).

Requires Apple Silicon and macOS 14 or later. On first launch the welcome
guide walks you through Microphone, Input Monitoring and Accessibility.

**Upgrading?** macOS may ask for Input Monitoring and Accessibility again.
If the switches look on but zappp says they're off, remove zappp from both
lists with **−** and allow it again.
